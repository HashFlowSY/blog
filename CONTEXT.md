# Blog Content

This context defines the written work and project evidence presented by the public personal site.

## Language

**Post**:
A published piece of technical writing with its own stable public identity.
_Avoid_: Note, article entry

**Project Case**:
A public account of a real project that the author completed or participated in.
_Avoid_: Project template, sample project, fictional case

**Template Case**:
An internal example used to help author a future Project Case; it is never public portfolio evidence.
_Avoid_: Project Case

**Draft**:
Non-public work in progress that is excluded from the published site.
_Avoid_: Published content
