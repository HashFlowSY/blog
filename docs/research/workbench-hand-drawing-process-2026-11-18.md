# 工作台透视手绘流程与分镜优化

2026-11-18 · 对照 `c57ab05` 逐笔绘制版与手绘示范。当前工作台见[现行绘制和交互](../design/workbench-interaction-design.md)。

建议先改开场的两轮浅稿。**第一轮定台面、桌脚和挂板之间的比例，第二轮交代每件物体放在哪、怎样站稳。** 这些关系成立之后，再压深轮廓、分层铺暗、补细节。工作台的绘制感来自能看见一个形体怎样从已有的几笔中长出来。[现有成稿](../design/workbench-2d/concept-1440.png)

## 这幅画适合参考哪种手绘

从成稿看，这是**有建筑和家具设计稿观感的铅笔透视速写**。略微俯视，能同时看到台面、柜体正面和侧面。米色纸底上有浅辅助线、深轮廓、灰色排线和局部接触影，黄色集中在一格抽屉。题材既有家具构造，也有物件在台面、搁板和地面上的位置关系。参考桌子与室内陈设的透视写生，再借石墨明暗和设计速写的点色处理。这里判断的是画面风格，原图具体用了什么工具和怎样落笔，仓库资料无法还原。[成稿](../design/workbench-2d/concept-1440.png) · [当前设计说明](../design/workbench-interaction-design.md)

有两点决定动画怎么取舍。设计师会在前段用轴线、盒形和椭圆建立大关系，后段仍会回来校比例与压重音。OpenSketch 的产品设计逐笔记录也观察到，学生与专业设计师普遍先画辅助结构，再画轮廓和折线，但两位专业设计师在辅助线用量上差异明显。因此这幅画需要的是让参照关系清楚，可以只表现几次典型的观察、落笔和修正。台面先落笔是一种适合本站的安排，Tom McPherson 的桌子示范在确定共享透视方向之后，也会先用一根近桌腿当定位线。[OpenSketch §7.1 与图 11–13](https://repo-sam.inria.fr/d3/OpenSketch/Gryaditskaya_OpenSketch_AuthorsVersion.pdf) · [Circle Line Art School 的桌子示范](https://www.youtube.com/watch?v=lwKSc-V8FP8)

## 建议的新分镜

| 顺序                      | 这一轮画什么                                                                 | 这一轮结束应看见什么                                   |
| ------------------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------ |
| 1. 浅点定比例             | 标台面两端、进深和最高处，选一条地面基准或落地点定高度。                     | 台、上架和地面大概占多高、多宽。                       |
| 2. 搭出台体               | 连出台面四边和厚度，从角点投下桌脚，分出柜体正面和侧面，连到挂板及两层搁板。 | 一张站在地上的桌子，有可以承托物件的面。               |
| 3. 放进物件               | 设备用薄盒和简化支架，凳子和花盆用中轴与椭圆，盒书和工具用简单大形。         | 桌上、架上、挂板和地面上的物件都有明确位置，主体完整。 |
| 4. 压主线，局部修正       | 桌沿、柜体转角、屏框和凳座的关键边压重，遮挡关系确定后提淡浅线。             | 前后层次清楚，能看见浅线如何被正式轮廓接住。           |
| 5. 铺暗，再回头压深       | 分出柜侧背光、搁板下投影与脚边接触影。铺浅灰，补有限排线和最深几笔。         | 即使暂时没有孔眼、螺丝和木纹，也能读出体积。           |
| 6. 加细节和黄铅笔色，抬笔 | 选几组工具、挂孔和屏幕小图补画，薄铺黄色并回描接缝。                         | 最后一笔完成后画稿已连续对齐，抬笔期间画面稳定。       |

第一轮样段建议用**台面四角 → 右侧柜体 → 显示器底座 → 凳脚投影**，覆盖定位、承托和铺暗三个最影响真实感的地方。比较新旧时先用同一播放时长，以原稿里边线朝向和物件位置为基准。若正常速度下看不清动作，优先压缩重复挂孔和木纹，把时间留给定位、回描和短排线。以视觉节奏决定总时长，现有 6.6 秒只是第一轮对照。

验收先看桌面和手机的正常速播放，再用固定帧核对三件事。浅稿结束时主物件已经站稳。画笔抬起换位置时没有墨迹跟随，铺暗从本地笔触附近逐次累积。最后一笔前后检查抽屉边、屏框和凳脚投影，整图交接时它们已经对齐。[现有固定时钟与笔尖对位检查](https://github.com/HashFlowSY/blog/blob/c57ab05f6eaa4ce5ee6e0a5090bfba1a26437660/e2e/helpers/workbench.ts)
