# 首页工作灯：柔和开关效果调研

2026-11-16。本记录比较方案 B 落地前，首页二维铅笔工作台的几种开关灯试作。当前行为见[工作台设计说明](../design/workbench-interaction-design.md)。

## 建议

先试 **B：灯条更快变亮，挂板和台面同时在原处渐亮**。暖亮集中在灯罩下沿及紧邻的挂板，露出的台面只变一点。关灯时灯条更快变暗，两个受光面柔和地回到环境光。光晕中心、范围和遮挡边界固定，由各层强度表达灯源与反光的差别。

用 **A：固定区域同步渐变** 做最简单的对照。如果 A 在实际尺寸已经能让人一眼认出灯开关，就没有必要为了动效再加一层光晕。**C：局部暖色过渡** 适合作对照，比较「少一点明暗、多一点色温」是否更贴近纸面。先看哪一种的关灯画面自然，再比节奏；两张静态图之间的光不可信，时序调得再细也补不上。

## 为什么此前试作会像扫光

[概念图](../design/workbench-2d/concept-1440.png)里的灯在顶层搁板下面，是一条细长光源。挂板上的孔、工具轮廓和台面排线都很清楚；首页本身的暖纸色不随工作灯开关。原画已是默认亮态，[设计说明](../design/workbench-interaction-design.md)和[视觉验收](../../design-qa.md)要求收笔成稿与概念图对应选区的 RGB 零差异。

扫描试作已有两块固定的软暗部。挂板径向渐变中心不透明度为 `0.22`，台面扁椭圆为 `0.09`，灯条素材单独变暗。中间帧额外绘制一个沿 `y = 190 + light × 310` 移动并变宽的高亮，还用同一位置的线性遮罩逐行切换暗部。以 [390 像素宽的手机取景](../../src/components/home/assembly-workbench.module.css)估算，光斑位移约 157 CSS 像素。试作的过渡约 720 毫秒，当时的测试验证开灯时挂板先亮、关灯时台面先暗。降亮度、加大模糊或缩短时间只能减弱这条边界，位置仍会移动。

## 三种画面方向

| 方向                        | 开灯时看到什么                                                                                                                         | 与现有画稿的适配                                                                                              | 取舍                                                                                                                 |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **A．固定区域同步渐变**     | 灯条、灯下的挂板、露出的台面从同一时刻开始改变，灯条的两态差最明显；变化结束后正好回到原稿。                                           | 在现有挂板、台面静态渐变和遮挡上加同一个强度值，去掉移动高亮与移动遮罩。动作前后没有新增光源形状。            | 很轻，能用来确认空间上不动是否已经足够。挂板大、灯条细，缩小观看时如果三个区域的差异差不多，可能更像插画局部调曝光。 |
| **B．灯条明确，受光面轻跟** | 靠灯条的低饱和象牙色先变清楚，近处挂板和台面几乎同时跟上。光晕沿灯条拉长、很浅，在原处淡入；关闭时源头先暗，背景很快回到原来的环境光。 | 沿用 A 的固定遮罩。灯条及相邻一小圈和受光面分开调强度；优先通过关灯态减掉近灯处亮度，让原画暖亮在开灯时恢复。 | 更容易把局部变亮归因到灯本身。如果灯条亮过最终成稿、光晕太宽，或受光面晚很多，则会像闪一下、起雾或出现下一轮扫光。   |
| **C．固定区域色温过渡**     | 灯下小块偏暖，关灯时退回同一张纸的环境色；灯条本身仍有明暗区别。                                                                       | 继续使用相同裁切，只在局部两态之间混合颜色，浅暖灰到纸色附近即可。桌外暖纸底、屏幕、抽屉共用原色。            | 能保留微妙的光感，也最容易弱到看不出来。单纯加黄会像压了一块色纸；别为了突出变化把关灯态推成蓝灰或把开灯态推成发橙。 |

还可以画一张固定、淡淡的空气光锥。在目前靠表面亮度表示光线的原画里，锥形轮廓和空气里的蒙层很可能被看作雾或舞台灯。若 A/B 的渐变看起来像覆盖原稿，可以改用**手工绘制的关灯差分图层**，在原坐标逐处处理灯罩、挂板和桌沿，保留原线条、纸纹和小物件。两态之间只淡入局部差分，亮态仍使用原成稿。这样可以分别处理工具、木头和纸，也需要额外维护素材对齐、体积和预加载。用原成稿作底、只叠一层差分，可以避免两张半透明全图交叉混合时漏出网页底色。[合成规则](https://www.w3.org/TR/compositing-1/#porterduffcompositingoperators_srcover)

## 对照样片记录

在同一张工作台成稿上，以 Chromium 独立渲染三种局部动效，合成到 1.5 倍慢放的 GIF。比较时使用相同的纸面和开关灯端点。样片 A 的光源、挂板与台面均用 240 毫秒。B 的灯条约 105 毫秒，两个受光面约 285 毫秒，额外加一抹固定的浅暖晕以便看清差别。C 约 355 毫秒，给受光区短暂加暖后回到原画。

- A 的画面最安静，但开灯早期容易读作一整块纸面变亮。可把它保留为零装饰的参照。
- B 的前几帧最容易辨认是灯条发亮，挂板与台面的变化留在原处。样片刻意放大了暖晕供对照，实装应先降低暖晕，并确认任意中间帧都没有亮过最终成稿的闪峰。
- C 的暖色在画稿上可见，尤其是挂板中央。它容易形成一块短暂偏黄的区域，适合在 B 的基础上局部少量使用。

将开灯中间帧缩到接近 390 CSS 像素手机上的画稿比例，B 的灯条仍是画面里最容易辨认的变化，台面反光则更轻。样片用于判断局部的变化形状与节奏。各图的持续时间不同，观察结果也包含速度差异。正式取舍仍需在正常速度的真实首页与手机裁剪上复验。

## 怎么试 B

1. **先定两张静止画面。** 亮态完全使用现有成稿；暗态只对灯条、其紧邻的挂板和露出台面调暗。比对灯罩下沿有没有白边，挂板孔和铅笔排线有没有被糊住，台面有无独立椭圆贴片感。在正常网页尺寸看得出开关时，只在局部放大检查边缘，不以放大图定强度。之前的关灯测试约束是灯条至少差 25、挂板至少差 12、台面至少差 7（实现中使用的亮度采样单位）；这个排序有用，具体数值可随选定画面调整。
2. **先试短、重叠的节奏。** 灯条、挂板、台面都从触发后的首帧变化。灯条约 `90–120 ms` 收住，两个受光面共用约 `220 ms` 的过渡，可与 `180 ms`、`260 ms` 比较。关灯时受光面可从 `140–180 ms` 起试。若需要暖晕，沿灯条下沿放一个固定、扁平的暖白渐变，中心不透明度先试 `0.08–0.14`。这些是调试起点。优先将暖晕画进亮暗差分的固定分布，这样亮度随同一进度单调变化，也能维持亮态像素。
3. **沿用现有坐标和状态。** [灯罩素材、挂板与台面路径](../../src/components/home/workbench-art.ts)使用 `1440 × 900` 坐标，已排除笔记本、显示器及外接键盘。把 `light` 理解为强度值，固定渐变 `transform`、路径、遮罩尺寸与位置；用单调的强度曲线映射到灯条和受光面。反向操作从当前画面继续，避免半途按回时重播起点。保留亮态结束移除效果层的做法，可直接复用现有 RGB 基线验证。无需为这个效果先引入 Canvas、WebGL 或新依赖，性能仍以真实 Chromium 和 WebKit 的画面为准。

## 验收建议

| 检查               | 看什么                                                                                                                                                                                                                                                                                                                                                              |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 实际观看           | 用桌面首页和手机实际裁剪分别开关灯，先不解释效果。能看出变化由灯条发起，挂板、台面只在原处明暗变化，开和关都没有横带、硬边、雾和重影。若选 B，暖晕刚好依附灯条，按一次只变化一次。建议先看 A/B 一样强的关灯图，再看各自正常速度的片段。                                                                                                                             |
| 亮态、暗态与中间帧 | 默认亮态及关闭后再亮与原稿像素相同；暗态灯条清楚可辨，挂板次之，台面更轻。截取若干中间帧（按过渡进度约 25%、50%、75%），在无其他交互时，灯条、挂板、台面采样都应沿同一方向到各自端点，不应出现移动亮区、短暂亮过亮态或暗过暗态。                                                                                                                                    |
| 光影范围           | 对屏幕、抽屉、桌外纸面做稳定选区的像素比对，兼看挂件、键盘与屏幕边缘是否漏光。比较不同帧的局部差分时，先按该区域的开关最大差值归一；固定软渐变会随强度露出更多低对比边缘，仅用各帧同一个硬亮度门槛，有可能误判为面积扩张。                                                                                                                                          |
| 交互与回归         | 鼠标、Enter/空格和触屏均能切换，按钮名称、按下状态、状态播报正确；半途连按能从当前强度返回，最终落在最后一次操作指定的端点。减少动态效果时首帧即到端点。用 Chromium、WebKit 复核，合并检查电脑画图或叶片摆动同时进行时颜色与层级关系有没有改变。若实施，需要把原来断言「台面先暗 / 挂板先亮」的测试改成验证固定范围和亮度变化；保留无关区不变、端点像素及操作断言。 |

以上结论来自原稿、现有代码、一手资料和独立样片。亮度、暖色偏移与缓动仍取决于真实取景下的观感。
