# 三维工作台怎样对齐二维铅笔稿的几何

建议先把现有实体按原稿校准为同一份几何母版，再由这份网格和参考相机输出 2D 成稿的结构边、遮罩与 3D 默认帧。这样可以让两种状态共享轮廓、部件位置和遮挡关系。原画笔触沿用此前的纹理方案，背面、底面和内部接头用尺寸或补视图定稿。 [Debevec 等，约束建模 §2](https://www.pauldebevec.com/Research/debevec-siggraph96.pdf) · [FreeCAD TechDraw，由模型生成视图](https://github.com/FreeCAD/FreeCAD-documentation/blob/main/wiki/TechDraw_View.md) · [工作台纹理调研](workbench-texture-research.md)

## 当前模型的偏差

仓库中的设计依据是二维插画及其成稿图层。当前模型先用固定的透视相机把画面标定点投到指定平面，再用矩形、圆柱和挤出轮廓生成实体。部分函数保留一条边或一个角，随后以平均深度、共用宽度或装配点调整其余角。旋转时这些几何保持固定，画面的遮挡和透视由观察相机计算。 [设计素材](workbench-source/) · [参考相机与射线求交](../../src/components/home/workbench-view.ts#L27) · [桌板矩形化](../../src/components/home/workbench-model.ts#L289) · [交互时的相机更新](../../src/components/home/workbench-scene.ts#L169)

对 `e0c5029` 做了裸网格重投影。用运行时的参考相机把实际三维坐标投到 1536 × 1024 原稿坐标系，和代码已有的原画标定点比较。叠图以首页的三个成稿图层为底图，蓝线为所选实体在该角度的可见边界，橙点为原画标定点，蓝点为相应的几何位置。数值反映这组标定点的偏差。 [网格叠图](../../qa-evidence/workbench-geometry-research/geometry-overlay.png) · [测量坐标与计算结果](../../qa-evidence/workbench-geometry-research/projected-geometry.json)

## 单张原稿能确定哪些几何

- **可见边和角点提供投影位置。** 一个像素对应从相机出发的一条射线，射线与已知平面相交才得到该面上的三维位置。若能从原稿可靠地估计参考平面的消失线和另一方向的消失点，可以估计平行平面间的相对距离。已知的参考尺寸能给相应测量定标。桌腿脚点可用共同地面，桌板上缘可用共同顶面。 [Criminisi、Reid 和 Zisserman《Single View Metrology》§3](https://www.robots.ox.ac.uk/~lav/Papers/criminisi_etal_ijcv2000/criminisi_etal_ijcv2000.pdf)
- **轮廓和遮挡约束可见范围与前后顺序。** 同一条投影视线上的部件可以有多种深度。若几组尺寸投影后仍落在同一条笔迹内，或某个凹槽一直被挡住，单张原稿会容许多个模型。背面支撑的走向、抽屉深度、桌底接头和孔是通孔还是盲孔，需要尺寸、剖面、补视图或明确的设计决定。多张外轮廓也只能限定与这些轮廓相容的体积。 [Laurentini，视觉外壳](https://cgvg.polito.it/vhull.html) · [Wesley 和 Markowsky《Fleshing Out Projections》](https://bitsavers.org/pdf/ibm/IBM_Journal_of_Research_and_Development/256/ibmrd2506I.pdf)
- **手绘线条带有笔宽和局部偏差。** 先识别哪几笔表示同一条结构边，再核对平行边是否共享消失方向、同一平面上的部件能否同时贴合、遮挡是否符合装配关系。若这些条件在笔宽容差内仍无法同时满足，保留具体冲突位置与误差，按设计意图确认应调整哪条成稿线或哪项几何假设。 [Lipson 和 Shpitalni，手绘线稿的软约束重建](https://www.mit.edu/~hlipson/papers/freehand.pdf) · [Masuda 和 Numao，投影图中的冲突线与漏线](https://research.ibm.com/publications/a-cell-based-approach-for-generating-solid-objects-from-orthographic-projections)

## 参考机位和实体怎样一起对齐

1. **在原稿坐标里做一张标注图。** 使用 `1536 × 1024` 成稿坐标，记录桌板、桌腿、洞洞板、抽屉、屏幕和凳面的关键点、可见边、按部件区分的轮廓与遮挡交界。用直线中心标注桌沿和屏幕框，用曲线标注凳面等视点相关轮廓。把木纹、排线、重描和阴影留给材质验收。用轮廓重叠区和穿出边界的位置分辨错位发生在哪个部件。 [Façade 的标注与重投影方法](https://www.pauldebevec.com/Research/debevec-siggraph96.pdf) · [Liu 等《Soft Rasterizer》的轮廓拟合](https://arxiv.org/abs/1904.01786) · [工作台参考机位](../../src/components/home/workbench-view.ts#L3)
2. **先求一台共同相机。** 从桌板长短边、柜体边与可信的竖边分组拟合消失方向，长直边优先。单独倾斜的屏幕和散放工具按各自姿态建模。把现有相机、消失点求得的针孔相机作为候选，原画中多组对应线几乎平行时再加正交相机候选。用未参与拟合的结构边检验各个候选。透视求解中固定世界原点和坐标轴，保留原图裁切带来的主点偏移。有已知尺寸时用它定标，只有原稿时可以先以桌板宽度为单位记录相对尺寸。已有可靠的三维控制点和相机内参时，可以用 `solvePnP` 求相机位姿，再看像素重投影误差。 [fSpy 相机标定](https://fspy.io/tutorial/) · [OpenCV 的 PnP 位姿计算](https://docs.opencv.org/4.x/d5/d1f/calib3d_solvePnP.html) · [Three.js 正交相机](https://threejs.org/docs/pages/OrthographicCamera.html)
3. **用共享尺寸生成整件。** 从桌板和桌架开始，把板厚、腿距、接触面、孔距和凳面半径写成部件参数。平行、垂直、共面、同尺寸和装配接触等已经确认的关系直接写入建模约束。用一个俯视轮廓加厚度就能定义形状沿厚度恒定的板件。屏幕支架、抽屉轨道和工具的转折与厚度则由各自的剖面或装配关系定义。现有 `artworkPoint` 可提供已知平面上的初始坐标。最终用共同参数生成所有面和接头，确保背面与底面能接上。 [FreeCAD Sketcher 几何与尺寸约束](https://github.com/FreeCAD/FreeCAD-documentation-docusaurus/blob/Stable/docs/workbenches/sketcher.md) · [CadQuery 草图与拉伸](https://cadquery.readthedocs.io/en/latest/sketch.html#workplane-integration) · [现有射线求交](../../src/components/home/workbench-view.ts#L52)
4. **联合拟合可见误差。** 先锁定相机拟合主要结构，再允许相机和少量实体参数联合微调。目标函数包含角点重投影距离、对应线段的垂直距离、可见轮廓的双向距离，以及相交位置的前后顺序。用部件 ID 和深度判断实际露出的边。标注权重按笔宽和置信度设定，可用 Huber 损失减弱错标与重描的影响。逐部件留存残差图。对背深、厚度等关键参数做小范围扰动，若显著改变侧背面却几乎不影响参考图残差，就标记为待尺寸确认。 [Debevec 等，边重投影与初始化 §2.3–2.4](https://www.pauldebevec.com/Research/debevec-siggraph96.pdf) · [Ceres Solver 的残差、边界及稳健损失](https://ceres-solver.readthedocs.io/latest/nnls_modeling.html)

## 本项目的实施顺序

1. **先定桌架和相机。** 在一张标注图里标出台面四角、前后沿、桌腿落点、柜体与背板接点、上层搁板和灯的位置。按一个参考机位拟合，再共同求桌板、立柱、横梁和搁板的尺寸与连接。台面上表面和地面定义各部件的接触高度。
2. **用同一相机做三个结构样段。** 桌架样段先收敛桌板后角、搁板右端和右后腿。大屏样段把外框的长宽、姿态、支架和底座一起对齐。圆凳样段用完整的凳面轮廓及脚点拟合，保持座面、支柱和脚环共轴，脚端共面。每个样段先看裸网格，再看从原角度轻拖、侧转和仰视时的遮挡。
3. **扩展到完整装配。** 样段通过后处理抽屉边与拉手、下层搁板与箱盖、键盘、灯条、钳工和挂板工具。保留能区分结构的倒角、孔洞、厚度和接缝。背面、底面和接头从带尺寸的补视图或经确认的结构设计取得。
4. **从定稿网格输出成稿形体。** 用参考相机输出可见轮廓、部件遮罩和遮挡关系，按这些边界整理原画笔触并接回现有点、线、面绘制流程。运行时从同一参考姿态进入绕转，使用同一份固定几何。

相机和尺寸拟合可以离线完成。现有 Three.js 网格可先用于样段，把同一部件的尺寸和装配基准集中定义，再生成各面的顶点和绘制遮罩。复杂的钳口、工具箱扣具或灯具外壳也可离线建模，按同样的相机及装配基准验收后纳入整件。

## 首次拖动与全角度验证

当前相机支持连续水平绕转和接近正顶、正底的视角。交互验收覆盖这些角度，正投影的顶视图和底视图用于尺寸复核。交互期保持固定的部件尺寸和连接，只更新相机姿态。 [绕转范围与初始姿态](../../src/components/home/workbench-scene.ts#L87)

- 在相同参考机位和裁切下输出原稿、仅用几何生成的部件轮廓与深度、最终铅笔帧。按部件比较角点重投影误差、轮廓距离、孔洞和遮挡顺序。样段可把清晰结构角点的 95 分位偏差设为不超过 2 个原图像素，轮廓偏差按原稿的一笔宽度验收，并保留几处未参与拟合的锚点。先用原图坐标度量，再检查桌面和手机视口。采用 3D 母版时，另在固定参考机位比较两种状态的部件遮罩与可见边。
- 记录按下前、按下未移动和首个实际移动帧。用首个拖动帧的相机姿态单独渲染同一网格，核对画面中的位置变化与真实转角相符。再绕行至少一整圈并查看正侧、后侧、斜上、近顶、斜下和近底，核对桌腿落点、凳脚、横梁、柜体和工具之间的连接是否连续。回到参考姿态时核对构图与轮廓，几何验收完成后再看笔触和合成差异。
