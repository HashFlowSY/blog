## 阻尼、惯性与同时触发

把离开休止位的角度记为 `θ`，小幅转动可用 `Iθ″ + cθ′ + kθ = τ`。`I` 是绕轴转动惯量，`c` 是角阻尼，`k` 是等效回正刚度。平移换成质量 `m` 和位移 `x`。同一角冲量 `J` 对应 `Δω = J/I`，转动惯量大的部件初始反应较小。欠阻尼频率与 `k/I` 和 `c/I` 共同有关。扳手近似小角物理摆时，重力提供的回正刚度为 `mgd`，其中 `d` 是重心到轴的距离。同形状、同比例加重时，`I` 与 `mgd` 随质量同比例变动，摆动周期主要由重心和质量分布决定。叶片可用较低的有效惯量和弹性参数表现轻柔回弹，数值是美术参数，等模型和观感确定后再标定。 [OpenStax 阻尼振动](https://openstax.org/books/university-physics-volume-1/pages/15-5-damped-oscillations) · [OpenStax 物理摆与扭摆](https://openstax.org/books/university-physics-volume-1/pages/15-4-pendulums)

每次扫过可注入一个限幅角冲量。欠阻尼时用时间戳直接求 `θ(t) = e^(−at) [θ₀ cos(bt) + ((ω₀ + aθ₀)/b) sin(bt)]`，其中 `a = c/(2I)`，`b = √(k/I − a²)`。再次触发时在事件时刻取出当前角度和角速度，再把冲量加到当前角速度，位置连续。按指针速度与运动方向给冲量，并设置短暂的重复触发间隔。若净空允许的对称摆幅为 `θmax`，可将每次加冲量后的机械能 `½Iω² + ½kθ²` 限在 `½kθmax²` 以内，利用自由振动中能量持续衰减的性质约束后续摆幅。指针持续停在同处时由部件自行收敛。在位置和速度同时低于阈值时写回精确休止位并停止更新。用相同的事件与时间戳在不同刷新率下复测。 [OpenStax 阻尼振动](https://openstax.org/books/university-physics-volume-1/pages/15-5-damped-oscillations) · [HTML 动画帧回调](https://html.spec.whatwg.org/multipage/imagebitmap-and-animations.html#animation-frames)

`MathUtils.damp` 是一阶指数趋近，适合手柄等单调回位的动作。箱盖和抽屉若需要明确的开闭时间，可用带限位的进度曲线，切换方向时从当前进度继续。圆凳的减速用限定行程内的速度曲线表现，收尾保持脚底接地。对叶片与挂件用独立状态，对同一轴同一时刻只由一个动作控制。 [Three.js r187 MathUtils.damp](https://github.com/mrdoob/three.js/blob/r187/src/math/MathUtils.js#L134-L138)

可在制作阶段先算出各部件整个行程的扫掠范围，检查相邻扳手、叶片与盒子、箱盖与横梁、凳脚与桌脚和抽屉。粗包围盒用来找可能相交的对象，对候选再核对实际轮廓和净空。只比较起终点会漏过中途接触。相邻活动件的扫掠范围重叠时，先试缩小各自角度或让后触发者延迟。需要接触时停在首次触碰位置，保留共存的无干涉动作。 [Three.js Box3](https://threejs.org/docs/pages/Box3.html) · [Rapier 连续碰撞检测](https://rapier.rs/docs/user_guides/javascript/rigid_bodies/#continuous-collision-detection)

## 台钳的丝杆和手柄

从手柄端看，逆时针让活动钳口远离固定钳口，顺时针把工件夹住。以张开量 `x` 为状态，手柄和丝杆转角为 `2πx/p`，其中 `p` 是每转一圈的推进量。活动钳口沿丝杆轴移动，丝杆尾端在最大开度仍与固定体啮合。预览从夹持位置转三圈走到开度限位。 [Eastwood 台钳说明书](https://www.eastwood.com/images/library/30115Q.pdf) · [Yost 旋转和直线行程说明](https://www.eastwood.com/images/library/72862Q.pdf)

木块夹在靠外的位置，松到可脱离时向外侧翻落。它接触桌面后弹起一次，继续向外转动，越过桌沿后加速下落。触地后再轻弹一次，然后短滑停稳。合拢时，木块沿一条抛物线从地面越过桌沿，回到原夹持位置。沿弧线连续调整速度，起步和落位逐渐过渡。钳口为放入动作保留开度，木块落位后再夹紧。快速合拢时，木块先完成落地和回弹，再开始回程。

直接拖手柄时，用指针射线与手柄转动平面求交，累计两次交点相对轴心的有符号角差，再按螺距更新行程。手柄视角接近侧面时，点按或原生按钮仍可执行完整开合。单指释放时停在当前开度。相机绕转继续由画布其余区域处理。 [Three.js Ray.intersectPlane](https://threejs.org/docs/pages/Ray.html#intersectPlane) · [WCAG 2.2 拖动操作](https://www.w3.org/WAI/WCAG22/Understanding/dragging-movements.html)

## 命中、绕转和可访问性

1. **按当前实际投影拾取。** 把 `clientX/Y` 相对 canvas 的 CSS 边界转成 `[-1, 1]` 的归一化设备坐标。使用带裁切偏移和投影缩放的实际渲染相机 `camera`，先确保相机和对象世界矩阵与要拾取的画面一致。`orbit` 克隆相机只负责采集绕转与缩放输入，两者距离和投影可不同。`Raycaster` 按距离排序，先用部件拾取网格缩小范围，再检验到最近候选点之前的桌板、柜体和其他物件遮挡。可给薄小部件加随同部件移动的简单命中体，并对其超出实体的范围做遮挡检查。用候选列表或射线图层控制哪些对象参与命中。快速掠过细叶时再验证是否需要用相邻事件采样路径。 [Three.js Raycaster](https://threejs.org/docs/pages/Raycaster.html) · [Three.js 更新世界矩阵](https://threejs.org/docs/pages/Object3D.html#updateWorldMatrix) · [本项目相机和裁切](../../src/components/home/workbench-scene.ts#L120) · [Pointer Events 合并事件](https://www.w3.org/TR/pointerevents3/#coalesced-and-predicted-events)
2. **按下记录，抬起确认。** 锁定版本的 `OrbitControls` 会捕获指针，鼠标按下进入旋转状态就发 `start`，滚轮也会发 `start`/`end`。现有 `data-dragging` 因此不足以区分点按和拖动。可记录主指针 ID、按下目标与指针离开起点的最远 CSS 像素距离。低于经实测调整的阈值且抬起时仍命中同一目标，才执行部件动作。若点按中的轻微移动也应保持相机姿势，阈值要在指针移动交给绕转前应用。拖动、双指介入、`pointercancel` 或捕获丢失会清理候选。捕获会重定向事件目标，释放位置仍应用坐标拾取。空白处的双击复位可以沿用，部件上的快速连点与复位要有明确优先级。 [Three.js r187 指针与移动处理](https://github.com/mrdoob/three.js/blob/r187/examples/jsm/controls/OrbitControls.js#L1560-L1793) · [现有双击复位](../../src/components/home/workbench-orbit.tsx#L96) · [W3C Pointer Events](https://www.w3.org/TR/pointerevents3/#pointer-capture) · [WCAG 2.2 指针取消](https://www.w3.org/WAI/WCAG22/Understanding/pointer-cancellation.html)
3. **鼠标扫过与触屏点按分别触发。** 扫过只接收可悬停、未按下且实际移动的指针。相机绕转或缩放期间暂停新的扫过脉冲，先前动作可自行收敛。移动端以单指点按触发，已有单指绕转、双指缩放与画布外纵向滚动应保有可用空间。`OrbitControls.connect()` 在 canvas 上写入 `touch-action: none`。若需要在画布上纵滑页面，须在输入开始前选定触控模式或操作区域，浏览器已判定手势后再改 CSS 来不及。 [Three.js r187 touch-action](https://github.com/mrdoob/three.js/blob/r187/examples/jsm/controls/OrbitControls.js#L495-L507) · [W3C 直接操控手势](https://www.w3.org/TR/pointerevents3/#declaring-direct-manipulation-behavior) · [当前触摸测试](../../e2e/home.spec.ts#L333)
4. **为可操作部件提供原生按钮入口。** canvas 当前对辅助技术隐藏，外层可聚焦并接收绕转键。建议让 DOM 按钮与画布命中共用一个动作入口。用中文名称和可见焦点，Enter 或 Space 直接触发，开闭状态用稳定标签和 `aria-pressed`，状态变更可按需用简短文字表达。将现有方向键、Home 与指针按下聚焦限在画布操作区域，避免按钮事件冒泡时被接管。小物件在手机上用按钮保证点击范围。WCAG 2.2 AA 的目标尺寸基线为 24 × 24 CSS 像素，包含等效控件与间距等例外。若把部件做成拖动操作，需要保留点击或点按达到同一结果的路径。现有绕转和缩放本身若纳入 WCAG 2.2 AA 验收，也要检查单指可点击的替代控件，键盘快捷键满足的是另一项要求。 [当前键盘入口](../../src/components/home/workbench-orbit.tsx#L64) · [WAI 按钮模式](https://www.w3.org/WAI/ARIA/apg/patterns/button/) · [WCAG 键盘](https://www.w3.org/WAI/WCAG22/Understanding/keyboard.html) · [拖动](https://www.w3.org/WAI/WCAG22/Understanding/dragging-movements.html) · [多指手势](https://www.w3.org/WAI/WCAG22/Understanding/pointer-gestures.html) · [目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)
5. **响应减少动态效果偏好。** 建议在 `prefers-reduced-motion: reduce` 下，开合、侧移和电脑绘图直接呈现结果。鼠标按键以局部亮边表示已触发。保留原生按钮和结果状态。当前首页已支持跳过绘制动画，并在创建场景时关闭相机阻尼。 [现有绘制设置](../../src/components/home/assembly-workbench.tsx#L109) · [当前相机阻尼](../../src/components/home/workbench-scene.ts#L62) · [W3C 减少动态效果](https://www.w3.org/TR/mediaqueries-5/#prefers-reduced-motion) · [WCAG 交互触发动画，AAA](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)

## 2D 交接、空闲性能与验证

当前帧先渲染 WebGL，再按绕转相机是否离开参考位置切换显示。默认相机下做部件动作时，现有判断会把动作留在透明 canvas 下。建议在相机姿势之外检查部件姿势和正在播放的动作。新姿势已渲染后同一帧切至 3D。仍打开的抽屉、箱盖或移位的凳子保持 3D。相机和部件都回到休止位、也没有待播放动作时，回到共用铅笔图集生成的 2D 成稿。复位应明确相机与部件的范围。 [现有帧交接](../../src/components/home/workbench-scene.ts#L120) · [两层显隐](../../src/components/home/assembly-workbench.module.css#L56) · [2D 成稿](../../src/components/home/workbench-reveal.tsx#L142)

是否显示 3D 和是否需要下一帧用两个独立条件。静止开着的抽屉保留最后一帧，下一次绕转、点按、纹理更新或尺寸变化再请求渲染。一个 `requestAnimationFrame` 同时更新相机阻尼和仍活动的部件，最后一帧写回准确姿势并完成显隐。没有动作时只处理实际输入，悬停拾取合并到最多每帧一次，重复使用射线和结果数组。隐藏标签页、离开场景和卸载要清理或暂停帧、监听和屏面资源，恢复时按选择的时间语义从暂停点继续或收尾，避免累积整段后台时间。当前模型卸载已取消待执行的帧。 [现有按需帧与卸载](../../src/components/home/workbench-scene.ts#L120) · [Three.js 按需渲染](https://threejs.org/manual/pages/rendering-on-demand.html) · [HTML 动画帧回调](https://html.spec.whatwg.org/multipage/imagebitmap-and-animations.html#animation-frames)
