# 工作台几何与铅笔纹理统一方案

以现有 1536 × 1024 铅笔稿为美术参考，以定稿的实体模型为几何来源。参考机位的三层 2D 成稿与交互 3D 共用模型、贴图和相机。点、线、面的绘制结束后，从同一构图进入连续 360° 绕转。 [几何调研](workbench-geometry-research.md) · [纹理调研](workbench-texture-research.md)

## 几何与装配

1. 用桌面、桌腿落点、搁板和屏幕边框的结构点在同一参考相机下校准部件。桌面以矩形拟合四角，桌腿共用地面并受桌板范围约束。搁板、立柱、洞洞板和支撑件按装配关系连接。
2. 大屏按四个角联合拟合平面，显示器底座贴合台面。凳面、支柱与脚环共轴，凳脚按原稿投到同一地面。抽屉面板共用宽度，拉手、箱盖、工具、键盘与台钳有实体厚度。
3. 原画可见结构以原稿的轮廓和遮挡顺序校准。背板支撑、桌底连接和箱体内外面依据可见装配关系补全。单张稿里的隐藏结构由这份模型定稿。 [实体模型](../../src/components/home/workbench-model.ts) · [参考相机](../../src/components/home/workbench-view.ts)

## 贴图与绘制

1. 根据原稿图层和部件遮罩判断笔迹归属，并用参考相机的深度与可见表面筛选样本。台沿、桌面、屏幕和抽屉等有明确边界的平面按四角对应关系校正采样位置。
2. 把原稿笔迹和补绘排线离线烘焙到实体表面的 UV 图集。侧面、背面、底部以及被遮挡处使用固定在模型表面的铅笔纹理。挂板由实体网格提供通孔，底色取自去除工具和孔印后的原稿色调。展开边缘保留扩边，便于旋转、放大和缩小时过滤。
3. 以同一图集渲染参考机位，将可见像素按绘制顺序分成工具、桌架和台面三层。铅笔按笔划遮罩逐步揭示成稿。首拖切换到已经绘出的 3D 帧，复位回到同一机位。 [UV 布局](../../src/components/home/workbench-atlas.ts) · [烘焙脚本](../../scripts/bake-workbench.mts) · [交互场景](../../src/components/home/workbench-scene.ts)

## 验收与重新生成

精细建模采用连续截面生成桌沿、台钳铸件、壳体和凳脚。钳口空隙、屏幕后壳凹槽、桌下线夹、工具箱铰链和穿孔挂钩使用实体几何。部件表面的接触暗线和磨痕随图集烘焙。原稿里的抽屉拉手笔迹在取样前以相邻区域的纸纹补齐，工具箱壳体和扣具按新实体补绘。 [截面构造](../../src/components/home/workbench-surfaces.ts) · [建模调研](workbench-detail-modeling-research.md)

在桌面视口 1440 × 900、DPR 2 下对比同一参考机位。此次 Chromium 取景区的 2D 与 WebGL RGB 平均绝对差为 3.17/255，旧版在同一取景区为 3.59/255。两端的过滤与抗锯齿仍有细微差异。原画中掠角的桌面和键帽以原画色调配合表面排线补绘，避免俯视时拉长旧边线。

本机 Chromium 在关闭缓存的情况下交替加载新旧静态产物各五次。画面完成到 3D 就绪的中位时间在桌面视口为 263 ms → 274 ms，在 390 × 844 的移动视口为 274 ms → 278 ms。三轮桌面拖动的中位帧间隔约 16.7 ms。模型为 52,848 个三角面和 9 个按材质合批的网格，图集为 2,402,250 字节。

- 用当前原画标定点检查桌板、大屏、抽屉和凳脚，用相同参考机位对比生成成稿和 WebGL 帧。
- 实际首拖、转满一圈、缩放、侧视、背视和仰视，观察笔迹与实体边缘的关系，并检查支撑、孔洞和底部构造。
- 用首页构建动画和静态产物测试验证导出的图片、触控、键盘和复位。

修改几何、相机或笔触时，使用 `dwebp` 和 `cwebp` 读取源图层并重新生成 `public/assets/` 下的图集及三张成稿。Node.js 版本与仓库的 `.nvmrc` 一致。浏览器从静态资源读取烘焙结果。 [源图层](workbench-source/)

```sh
pnpm exec node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON scripts/bake-workbench.mts
```
