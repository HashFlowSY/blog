# 首页二维工作台

首页从米色纸面起笔。铅笔先把墙面、地面和透视线画成一张完整的底稿，再点出右桌脚。每次集中画一件物体，把轮廓、材质和局部阴影画完后再提笔移到下一件。[手绘流程调研](../research/workbench-hand-drawing-process-2026-11-18.md) · [概念图](workbench-2d/concept-1440.png)

| 时间           | 物体               | 落笔顺序                                                                                                                 |
| -------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| 0–3.80 秒      | 环境背景           | 在空白纸面上逐笔画墙面引线和地面透视，再以短排线补齐浅调。                                                               |
| 3.80–7.40 秒   | 桌子               | 定右桌脚，画完整台面、桌沿、桌腿、斜撑、下层搁板、柜体框架和桌脚附近的投影。                                             |
| 7.40–8.45 秒   | 左边桌下的箱子     | 沿已画好的下层搁板起稿，画箱盖、箱身、提手和接触影。                                                                     |
| 8.45–10.05 秒  | 右边的抽屉         | 定各层边缘，画灰阶纹理和拉手，再换黄笔给底层抽屉分笔上色。                                                               |
| 10.05–12.00 秒 | 背景洞洞板         | 画立柱和完整面板，按透视排孔，铺板面和边沿的底纹。                                                                       |
| 12.00–12.95 秒 | 洞洞板上面的架子   | 画架板厚度、左右支架和下沿阴影。                                                                                         |
| 12.95–14.30 秒 | 椅子               | 定轴线，画坐面、立柱、脚圈和脚撑，铺附近的接触影。                                                                       |
| 14.30–15.75 秒 | 左边电脑           | 在台面上定底座，沿边框画屏幕，再画键盘、屏内草图和接触影。                                                               |
| 15.75–17.30 秒 | 右边电脑           | 画支架、屏框、屏内草图、外接键盘和鼠标，最后画桌面上的铅笔。                                                             |
| 17.30–18.25 秒 | 台钳               | 先画底座，再加钳身、手柄和接触影。                                                                                       |
| 18.25–19.21 秒 | 架子上的植物       | 先画花盆，再向上画茎、叶片和叶脉。                                                                                       |
| 19.21–20.02 秒 | 植物右边的两个箱子 | 先画左箱的轮廓、箱身和提手，再画右箱。                                                                                   |
| 20.02–20.73 秒 | 书                 | 从左到右画书脊和厚度。                                                                                                   |
| 20.73–21.33 秒 | 小抽屉             | 画柜体、分层和拉手。                                                                                                     |
| 21.33–22.18 秒 | 灯                 | 画架板下的灯壳、灯罩和近处的暖光。                                                                                       |
| 22.18–24.78 秒 | 洞洞板上的工具     | 用更快的笔速从左往右依次画两把钳子、两把螺丝刀、五把扳手、T 形工具、中间的螺丝刀、工具杯、锤子、右侧长螺丝刀和短螺丝刀。 |
| 24.78–25.00 秒 | 收笔               | 缩短后的铅笔抬起离场，画面保留最后一笔。                                                                                 |

纸纹、承托面底纹和画稿就绪后，工作台进入视口即自动播放。先沿共用笔路画完整张环境背景，再固定已完成的背景笔迹。每个物体沿自己的笔路画出轮廓、原稿纹理和接触影。宽阴影和纹理由错开起落的短排线逐步铺满，排线在当前部件画完前覆盖完整。收笔前后使用同一张画稿和同一个遮罩。缩短提笔转场，并加快重复排线和小件铺纹。[播放入口](../../src/components/home/assembly-workbench.tsx) · [绘制时序](../../src/components/home/pencil-plan.ts) · [笔触与表面](../../src/components/home/workbench-geometry.ts) · [短排线](../../src/components/home/workbench-hatching.ts) · [绘制层](../../src/components/home/workbench-drawing.tsx)

桌子阶段铺好台面木纹、下搁板和桌底投影。洞洞板的立柱与下沿接到桌面，架沿和架底阴影在架子阶段画出。电脑、台钳、灯和挂件沿各自轮廓落笔，前面画好的木纹和孔点继续透出。椅子阶段沿椅面、立柱、脚圈和脚撑落笔，椅脚落笔时再铺接触影。[桌面底纹](../../public/assets/workbench-2d/workbench-table-texture.webp) · [洞洞板底纹](../../public/assets/workbench-2d/workbench-pegboard-texture.webp) · [架子底纹](../../public/assets/workbench-2d/workbench-shelf-texture.webp) · [椅后底纹](../../public/assets/workbench-2d/workbench-chair-background.webp)

铅笔按落笔进度缩短，抬笔移动时保持当前长度。笔尖跟随笔迹，笔尾沿笔杆向前移动。以 1440 像素桌面画幅计，起笔时可见笔长约 150 像素，最后一次抬笔时约 94 像素，换算约 2.5 厘米。[笔尖与笔长](../../src/components/home/workbench-pencil.tsx)

相邻物体在原稿上的取样范围有交叠。显示器与 T 形工具、显示器底座与键盘、花盆与左箱、相邻书脊分别沿实际边线划分。前一件在抬笔时已画好边缘，下一件从自己的轮廓开始。挂板工具也按相同原则划分，锤头与右侧长螺丝刀用折线沿接头分开。短螺丝刀上方的孔随洞洞板画出。[物体交界](../../src/components/home/workbench-geometry.ts)

首次访问时，图注中的「直接体验」可随时切到成稿。键盘激活后可直接按空格切换工作灯。绘制中切到后台会暂停，回到页面从原处接着画。同一标签页内返回首页或刷新时显示成稿，选择「重看绘制」可从头观看。系统开启减少动态效果，或纸纹、承托面底纹加载失败时，直接显示原始成稿。铅笔素材失败时仍播放笔触。成稿加载失败时播报错误，部件素材失败时保留成稿并播报部件载入失败。

收笔且部件素材就绪后，可操作笔记本、外接显示器、外接键盘、盆栽的三个叶片区域和工作灯。系统开启减少动态效果时，叶片保持静止，激活电脑时播报「图纸已就绪」。

| 部件                 | 操作和结果                                                                         |
| -------------------- | ---------------------------------------------------------------------------------- |
| 笔记本               | 激活后先显示键位反馈，再在笔记本屏幕逐笔绘图。                                     |
| 外接显示器、外接键盘 | 两个入口都触发外接键盘的键位反馈和显示器的逐笔绘图。同一时间只播放一台设备的动画。 |
| 盆栽                 | 鼠标扫过或激活任一叶片区域时，该处枝叶绕连接点左右轻摆，邻近叶片小幅跟随。         |
| 工作灯               | 默认亮起。灯罩在原处泛起暖白光，挂板和台面一起渐亮。开启减少动态效果时立即切换。   |

成稿图注提示读者试开工作灯。触屏上，灯和外接键盘的命中区域以图上的部件为中心，高度至少 36 像素。键盘热区向上延伸至显示器附近，两者均触发外接设备绘图。手指从部件上开始滑动时，可以继续纵向滚动页面。用键盘聚焦部件后，按 Enter 或空格激活。[部件状态](../../src/components/home/workbench-interactions.ts) · [输入处理](../../src/components/home/workbench-interactive.tsx)

画纸、笔触、成稿和部件触发范围使用统一的 1440 × 900 坐标。屏幕绘图时在对应区域叠加遮盖图。叶片摆动时，固定背景补上纸纹和参考线。参与摆动的叶片连同叶柄围绕枝干上的连接点转动，连接点处保留一小段固定枝干。开关灯时，灯罩下沿的暖白光和挂板、台面的反光都在各自原处改变明暗。灯罩先稳定，挂板和台面同时开始、同步结束，完整过渡开灯约 220 毫秒、关灯约 170 毫秒。开灯状态稳定后与默认成稿逐像素一致。[插画坐标](../../src/components/home/workbench-art.ts) · [静态画稿和部件素材](../../public/assets/workbench-2d/)

用桌面和手机视口检查走笔顺序、部件内部的浅稿和抬笔时的稳定画面。对照空白纸面、墙面起笔和背景收笔，检查引线随铅笔推进，并以背景收笔帧为基准核对后续各阶段。检查洞洞板面纹理随短排线逐笔累积。减少动态效果时显示固定成稿，使用 Linux Chromium 的 1440 × 900 视口、DPR 1 逐像素对照概念图。交互检查覆盖电脑逐笔出图、叶片归位、工作灯开关、触屏直接点按和滚动、键盘操作及减少动态效果。[验收范围](../../design-qa.md)
