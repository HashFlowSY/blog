# 首页二维工作台

首页用一支铅笔从整体结构画到局部细节。第一笔落在右桌脚，从那里向上接出台面前沿，由右向左画到挂板左上方，再画搁板。电脑、凳子和工具随后落在已有的结构上。[手绘调研与分镜](../research/workbench-build-drawing-2026-11-17.md) · [概念图](workbench-2d/concept-1440.png)

| 时间         | 笔触与画面                                                                           |
| ------------ | ------------------------------------------------------------------------------------ |
| 0–1.25 秒    | 在右桌脚定点，上行至台面前沿，再从右向左连到上方挂板和搁板的结构线。                 |
| 1.25–2.65 秒 | 从台沿画出进深和厚度，为已围合的平面上浅调子，再用浅轮廓摆入设备、凳子、盆栽和挂具。 |
| 2.65–3.85 秒 | 沿草稿压深主要边线，已被补实或遮住的草线逐处退淡。                                   |
| 3.85–5.35 秒 | 沿搁板、台面、柜侧和脚边补暗部与短排线，并补齐挂孔和挂具细节。                       |
| 5.35–6.45 秒 | 先画笔记本和显示器里的小图，再在抽屉面内分三笔添黄，最后补台沿高光。                 |
| 6.45–6.60 秒 | 画面已与原稿对齐，铅笔抬起离场。                                                     |

等待素材期间显示静止纸底。画纸和成稿就绪且工作台进入视口后自动播放，约 6.6 秒收笔。开场笔画沿笔尖走过的路径留下。每处调子和纹理在所在部位的相关笔画完成后出现，画面逐处与原稿对齐。抬笔只移动笔尖，画面保持在概念图对应的成稿。[播放入口](../../src/components/home/assembly-workbench.tsx) · [绘制时序](../../src/components/home/pencil-plan.ts)

绘制中切到后台会直接收笔。刷新或通过浏览器历史回到首页会重新进入绘制流程。系统开启减少动态效果或纸稿加载失败时，直接显示可用的成稿。铅笔素材失败时仍播放笔触。成稿加载失败时播报错误，部件素材失败时保留成稿并播报部件载入失败。

收笔且部件素材就绪后，可操作笔记本、外接显示器、外接键盘、盆栽的三个叶片区域和工作灯。系统开启减少动态效果时，叶片保持静止，激活电脑时播报「图纸已就绪」。

| 部件                 | 操作和结果                                                                         |
| -------------------- | ---------------------------------------------------------------------------------- |
| 笔记本               | 激活后先显示键位反馈，再在笔记本屏幕逐笔绘图。                                     |
| 外接显示器、外接键盘 | 两个入口都触发外接键盘的键位反馈和显示器的逐笔绘图。同一时间只播放一台设备的动画。 |
| 盆栽                 | 鼠标扫过或激活任一叶片区域时，该处枝叶绕连接点左右轻摆，邻近叶片小幅跟随。         |
| 工作灯               | 默认亮起。灯罩在原处泛起暖白光，挂板和台面一起渐亮。开启减少动态效果时立即切换。   |

触屏可直接点按。手指从部件上开始滑动时，可以继续纵向滚动页面。用键盘聚焦部件后，按 Enter 或空格激活。[部件状态](../../src/components/home/workbench-interactions.ts) · [输入处理](../../src/components/home/workbench-interactive.tsx)

画纸、笔触、成稿和部件触发范围使用统一的 1440 × 900 坐标。屏幕绘图时在对应区域叠加遮盖图。叶片摆动时，固定背景补上纸纹和参考线。参与摆动的叶片连同叶柄围绕枝干上的连接点转动，连接点处保留一小段固定枝干。开关灯时，灯罩下沿的暖白光和挂板、台面的反光都在各自原处改变明暗。灯罩先稳定，挂板和台面同时开始、同步结束，完整过渡开灯约 220 毫秒、关灯约 170 毫秒。开灯状态稳定后与默认成稿逐像素一致。[插画坐标](../../src/components/home/workbench-art.ts) · [静态画稿和部件素材](../../public/assets/workbench-2d/)

用桌面和手机视口检查走笔顺序、局部纹理交接与抬笔时的稳定画面。成稿在 Linux Chromium 的 1440 × 900 视口、DPR 1 下对照固定概念图。交互检查覆盖电脑逐笔出图、叶片归位、工作灯开关、触屏直接点按和滚动、键盘操作及减少动态效果。[验收范围](../../design-qa.md)
