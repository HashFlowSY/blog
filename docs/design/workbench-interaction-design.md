# 首页二维工作台

首页先用铅笔标出定位点，再依次绘制上层搁板、挂板工具、台面左侧、台面右侧、桌下左侧和桌下右侧。每处先画轮廓，接着画完排线和细节，再移到下一处。最后一笔完成时即显示完整画稿。[绘制顺序](../../src/components/home/workbench-geometry.ts) · [概念图](workbench-2d/concept-1440.png)

收笔后可操作笔记本、外接显示器、外接键盘、三片叶子和工作灯。静止画面取自第二张概念图，包含同一画纸上的透视辅助线、笔触和阴影。

画纸和成稿就绪且工作台进入视口后自动绘制，约 4.8 秒收笔。加载期间，工作台透出首页底色。铅笔沿正在显示的笔画移动，消耗到末端时消失。绘制期间切到后台会直接完成，刷新或通过浏览器历史回到首页会重新进入绘制流程。系统开启减少动态效果时直接显示成稿，叶片保持静止，激活电脑时播报「图纸已就绪」。[播放入口](../../src/components/home/assembly-workbench.tsx) · [绘制时序](../../src/components/home/pencil-plan.ts)

| 部件                 | 操作和结果                                                                         |
| -------------------- | ---------------------------------------------------------------------------------- |
| 笔记本               | 激活后先显示键位反馈，再在笔记本屏幕逐笔绘图。                                     |
| 外接显示器、外接键盘 | 两个入口都触发外接键盘的键位反馈和显示器的逐笔绘图。同一时间只播放一台设备的动画。 |
| 三片叶子             | 鼠标扫过或激活其中一片时，目标叶片和相邻叶片轻摆，随后回到原位。                   |
| 工作灯               | 默认亮起。灯罩在原处泛起暖白光，挂板和台面一起渐亮。开启减少动态效果时立即切换。   |

触屏可直接点按。手指从部件上开始滑动时，可以继续纵向滚动页面。用键盘聚焦部件后，按 Enter 或空格激活。[部件状态](../../src/components/home/workbench-interactions.ts) · [输入处理](../../src/components/home/workbench-interactive.tsx)

画纸、成稿、动画遮罩和部件触发范围使用统一的 1440 × 900 坐标。绘图时在对应屏幕区域叠加遮盖图。叶片摆动时先补上露出的背景，再叠加旋转后的叶片。开关灯时，灯罩下沿的暖白光和挂板、台面的反光都在各自原处改变明暗。灯罩先稳定，挂板和台面同时开始、同步结束，完整过渡开灯约 220 毫秒、关灯约 170 毫秒。开灯状态稳定后与默认成稿逐像素一致。[插画坐标](../../src/components/home/workbench-art.ts) · [静态画稿和部件素材](../../public/assets/workbench-2d/)

桌面验收在 Chromium 的 1440 × 900 视口、DPR 1 下对照固定概念图。交互检查覆盖电脑逐笔出图、叶片归位、工作灯开关、触屏直接点按和滚动、键盘操作及减少动态效果。[验收范围](../../design-qa.md)
