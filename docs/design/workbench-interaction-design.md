# 首页二维工作台

首页先用铅笔标出定位点，再绘制轮廓、排线和细节。完成后，访客可以直接操作画里的部件。默认静止画面取自第二张概念图，保留同一画纸上的透视辅助线、笔触和阴影。[概念图](workbench-2d/concept-1440.png)

工作台进入视口后开始绘制。暂停后从当前笔划继续，刷新或返回首页时重新绘制。铅笔从落点开始留下图案，沿正在显示的笔划移动，消耗到末端时消失。系统开启减少动态效果时直接显示成稿。[播放入口](../../src/components/home/assembly-workbench.tsx) · [绘制时序](../../src/components/home/pencil-plan.ts)

| 部件             | 操作和结果                                                                                   |
| ---------------- | -------------------------------------------------------------------------------------------- |
| 盆栽、挂具       | 鼠标扫过或点按时轻摆，随后回到原位。                                                         |
| 台灯             | 点按切换明暗。                                                                               |
| 笔记本、外接屏幕 | 点按屏幕或对应的键盘后，键位依次反馈，接着逐笔显出屏内图纸。同一时间播放一台设备的绘制。     |
| 鼠标按键         | 左右键分别响应点按，并在短暂反馈后恢复。                                                     |
| 台钳             | 点按松开或合拢，也可拖手柄调整开度。松开到一定程度时木块落下，合拢时木块先回到钳口，再夹紧。 |
| 工具箱           | 先解扣再打开箱盖，合盖后重新扣紧。                                                           |
| 三格抽屉         | 点按可以拉出或推回。一次只打开一格，切换时先收齐当前抽屉，再打开最后选中的一格。             |
| 圆凳             | 点按往外移，再点回到原位。                                                                   |

点按、触摸和键盘操作共用一套状态。键盘聚焦后可用 Enter 或空格操作。触屏先点「操作工作台」，可随时退出，画面支持页面纵向滚动。以台钳手柄为起点拖动时可调整钳口。工作灯、箱盖、抽屉和凳子在本次访问中保持最近操作的状态。[部件状态](../../src/components/home/workbench-interactions.ts)

画纸、成稿、动画遮罩和部件触发范围使用统一的 1440 × 900 坐标。成稿显示原画，部件运动时仅替换动作所覆盖的区域。局部补画包含移开部件后露出的背景。部件回到原位时恢复同一张成稿。[插画坐标](../../src/components/home/workbench-art.ts) · [静态画稿和部件素材](../../public/assets/workbench-2d/)

桌面验收在 Chromium 的 1440 × 900 视口、DPR 1 下对照固定概念图。另验证部件开合和原位恢复、移动端滑动和点按、键盘操作及减少动态效果。[验收记录](../../design-qa.md)
