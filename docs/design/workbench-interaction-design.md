# 首页工作台部件交互设计

[打开本地首页](http://127.0.0.1:3000/) · [实现方案与资料来源](workbench-interaction-research.md) · [工作台建模与贴图基线](workbench-assembly-plan.md)

在绘制完成后，鼠标扫过树叶和挂件会带出短暂摆动。点按有实际用途的部件可以绘图、开箱、拉抽屉和挪凳。拖动画布用于 360° 查看，滚轮和双指用于缩放。从台钳手柄上起拖可以转动丝杆。铅笔线和纸纹随各自表面运动。

首页沿用点、线、面到整件的铅笔绘制。成稿后直接在画布上操作部件，观察角度由拖动和缩放控制。模型内壁和可动件一起使用首页的铅笔图集。

## 部件动作

| 部件                         | 触发范围                                     | 动作与恢复                                                                                                                                                                                                                                                           |
| ---------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 盆栽的叶片、细梗             | 鼠标扫到叶片或细梗，也可直接点按。           | 被触到的分枝从盆土接点轻摆，邻枝带出较弱的跟随摆动，盆土与盆体支撑不动。方向随掠过方向变化，幅度先试 4°–7°，约一秒收敛。停在同一片叶子时自然停稳。                                                                                                                   |
| 洞洞板的五把扳手             | 鼠标扫过单把，触屏点按单把。                 | 单把扳手围绕承重挂点作小幅钟摆，优先平行板面。长柄摆幅先限制到约 3°，短柄按实际净空调节。碰到邻件之前减小摆幅，挂钩留在板上。                                                                                                                                        |
| 板上的钳子、螺丝刀、锤形挂件 | 同扳手，命中哪件就响应哪件。                 | 钳口、手柄与各自工具作为一个刚体随挂点移动。轻件反应短促，锤形挂件起摆较慢。全部靠阻尼停回休止姿势。                                                                                                                                                                 |
| 横向工作灯                   | 点按灯罩或灯管。                             | 初始为开，关灯时灯管收暗，再点恢复。纸色和其余铅笔阴影保持稳定。                                                                                                                                                                                                     |
| 左侧笔记本、内置键盘         | 点按笔记本主体或键盘。                       | 随机依次按下键帽，只有当次键帽的四周亮起暖色细边。打字期间原稿淡出，最后一键弹起后依次画底座、立体轮廓、孔位和辅助视图，落到屏内原稿。                                                                                                                               |
| 右侧显示器、独立键盘         | 点按屏幕、屏框或桌上的独立键盘。             | 外接键盘按相同规则亮起各键边缘，随后大屏依次画外轮廓、中心线、同心圆和尺寸线。笔迹沿原图路径出现，屏幕和图纸位置固定。                                                                                                                                               |
| 右侧鼠标左键、右键           | 在模型上点对应键面。                         | 独立键片向下短行程再弹回，只有这片键的边缘发光，短暂停留后熄灭。滚轮和掌托壳构成固定参照。                                                                                                                                                                           |
| 台钳手柄、丝杆、活动钳口     | 点按手柄，或以手柄为起点沿弧线拖动。         | 从手柄端看，逆时针让活动钳口退开，顺时针合拢。木块翻落到桌面，弹起并越过桌沿，触地后再轻弹一次，随后短滑停住。松手可停在中间开度。合拢时木块沿抛物线越过桌沿，减速落回钳口，落位后再夹紧。 [Eastwood 台钳说明书](https://www.eastwood.com/images/library/30115Q.pdf) |
| 左下工具箱                   | 点按箱面、箱盖或前扣，开着时可点箱身或箱盖。 | 先让两个扣件解开，再沿真实后铰链抬盖，约 65°–68° 到限位。保持打开，可旋转查看箱内和后铰链。再点先合盖，再扣紧。前把手随箱身固定。                                                                                                                                    |
| 右柜上格、中格、下方黄格     | 点按各格面板或拉手。                         | 抽屉盒、拉手和可动轨沿柜体前向一起滑出，保留一段导轨咬合。拉出后可查看内壁，再点同一格推回。点其他格时，当前格先退回，新格再拉出。三格一次只开一格。                                                                                                                 |
| 圆凳的座面、支柱、脚环和凳脚 | 点按凳面的可见区域，也可点按凳身。           | 整张凳子沿桌子的横向向左挪一小段并停住。再点沿同一方向的反向回到原位。起停有惯性，座面朝向和厚度稳定，凳脚保持接地。                                                                                                                                                 |

电脑每次按 9 个键，打字约 1.8 秒，画图约 2.75 秒。台钳从夹持位置转三圈到开度限位，抽屉向外走约 0.74 个模型单位，凳子向左走约 0.72 个模型单位。

## 固定部件与装配关系

| 部件                                           | 设计处理                                                                               |
| ---------------------------------------------- | -------------------------------------------------------------------------------------- |
| 桌面、桌沿、桌腿、横撑、脚垫和下层搁板         | 保持刚体，支持从任意位置开始绕转。桌面承担设备和夹具的稳定参照。                       |
| 洞洞板、穿孔、背架、固定挂钩、螺钉和托架       | 留在结构上。挂件依照独立挂点摆动，从侧面依然能看到承托关系。                           |
| 洞洞板右侧挂篮及里面的细杆                     | 挂篮由两点固定，细杆由篮底承托。整体保留当前布置，提供遮挡。                           |
| 顶层搁板、盆栽花盆和盆土                       | 搁板承托上方物件。花盆和盆土是分枝摆动的固定支撑。                                     |
| 顶层书册、两个木盒及四格收纳柜                 | 保持闭合和原位。它们在首页的占用尺寸小，主开合体验集中于下方工具箱和右柜。             |
| 工作灯的外壳、支架和紧固件                     | 位置固定，灯罩和灯管区域共用开关入口。                                                 |
| 外接屏底座、支臂、电源排、背面线缆、插口和线夹 | 保持连接和位置。支臂、底座及桌下走线承担支撑和遮挡，显示器壳体和独立键盘负责触发动作。 |
| 桌上铅笔、鼠标外壳与滚轮                       | 桌面摆放位置固定，鼠标左右键独立活动。                                                 |
| 台钳底座与固定钳身                             | 固定在台面。活动钳口、导向滑块、丝杆和手柄承担开合，木块在足够的开度下离开钳口。       |
| 工具箱的箱身、脚垫、提手和铰链销               | 支撑面和销固定。箱盖带动盖侧铰链片，前扣在各自轴上活动。                               |
| 抽屉柜体、背板、层间隔挡和固定轨               | 柜体固定，抽屉及可动轨进出。开启时露出的侧面、背面和下缘按实体补齐。                   |

## 输入与动作规则

1. **绘制完成后再开放部件。** 每次进入或刷新按原有节奏播放绘制。完成后，鼠标落在可操作表面时显示指针。短动作由扫过或点按触发，停留时由部件自行恢复。
2. **以抬手确认点按。** 按下记录真实命中的部件，移动不超过 3 CSS px（鼠标）或 10 CSS px（触屏），且抬起仍在同一部件才执行。超过阈值时进入绕转。以台钳手柄为起点且能读出弧线时，手势用来转动手柄。第二根手指加入、指针取消或捕获丢失均放弃待确认的点按。射线取当前视角下最靠前的真实表面，桌板遮住抽屉时只命中桌板。 [Pointer Events 3](https://www.w3.org/TR/pointerevents3/) · [Three.js Raycaster](https://threejs.org/docs/pages/Raycaster.html)
3. **操作中仍能查看。** 箱盖、抽屉、圆凳和台钳可以在移动途中反向，从当前姿势继续。抽屉记住最后点按的格，前一格收齐后再执行。电脑一次只播一段完整的打字和绘图，播放完再接受两台电脑的新触发。鼠标按键独立响应，植物和单件工具可以并行衰减，拖动和缩放期间暂停注入新摆动。
4. **调整视角。** 画布获得焦点后，方向键控制旋转，加号和减号控制缩放。按 Home 或双击画布空白处回到初始视角，仍可查看打开的箱盖和抽屉。画布外保留页面纵向滚动空间。
5. **一轮浏览内保留工作台状态。** 箱盖、抽屉、工作灯、圆凳和台钳保持最近操作结果。重新进入或刷新从原始成稿姿势重新开始。系统开启减少动态效果时，开合、灯光和移位直接给出结果，点电脑立即呈现图纸，鼠标通过对应按键的亮边反馈。 [减少动态效果媒体查询](https://www.w3.org/TR/mediaqueries-5/#prefers-reduced-motion)

## 正式接入步骤

1. **标注装配与命中。** 在当前模型的表面数据上标出刚体、铰链、挂点、滑轨方向和休止姿势。按原有休止位置排 UV，静件仍共用合批网格。用首帧和成稿做像素对照，检查屏幕底座、台面、凳面和黄色抽屉的初始几何。
2. **先用重点部件做样段。** 用树叶和长扳手校准摆幅及拾取，用双屏与独立键帽校准边缘反馈、笔迹顺序和最终构图，用台钳验证螺距和开合边界，再检查工具箱与黄抽屉的内壁和滑轨。分开绘制接触暗线与物体自身笔触，打开后检查空位。
3. **接入绘制交接和其余部件。** 在原有帧时钟里增加部件状态。相机或部件有动作时先把同一帧的 3D 姿势绘好，再切换显示。默认视角且全部部件静止回位时显示原成稿。有部件保持打开时，保留最后一张 3D 帧，下一次输入才重绘。接入其余挂件、三格抽屉、圆凳和工作灯。
4. **按动作逐项验收。** 桌面和触屏各试点按、拖动、缩放、快速连点、取消指针、动画中复位、键盘操作和减少动态。分别从前、侧、背、上和下方看挂点、箱盖扫掠空间、柜轨、凳脚、笔触跟随和遮挡，截取首次切换帧查看是否闪白或重影。记录同设备下冷启动时间、实际绘制调用和帧时间，再与已有工作台基线对比。 [三维场景与性能调研](workbench-interaction-research.md#2d-交接空闲性能与验证)

## 审核时重点体验

1. 扫过树叶和相邻两把扳手，观察起摆方向、幅度和停止速度。再从扳手或抽屉上开始拖动，确认旋转时不会执行点按动作。
2. 分别点两台电脑，观察只有当前键帽亮边、最后一键弹起后才开始画图，以及两张图纸各自的起笔和补标注顺序。再点鼠标左右键，看光是否局限于当次按键。
3. 打开左下工具箱，拉出黄格后再点上格，把圆凳挪开再回位。观察打开后能看到多少内壁，以及每次只开一格、凳子固定向左挪的规则是否合适。
4. 放大后拖动台钳手柄，观察活动钳口能否停在中间开度。点手柄松开，观察木块在桌面和地面弹起。再点一次合拢，确认木块回到原位。
