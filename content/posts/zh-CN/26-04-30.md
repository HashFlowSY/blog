这份清单用于帮助初次接触 AI 服务中转站的人理解常见术语。价格、套餐和平台规则会变化，实际使用前仍应核对官方信息，并优先考虑账号、数据和支付安全。

## 术语表

### Anthropic 官方（Claude）

| 术语                         | 说明                                                                                                                  |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Free                         | 免费版。有消息上限，高峰期排队。                                                                                      |
| Pro                          | $20/月。用量比 Free 多，具体多少官方不说，可以网上看实测。                                                            |
| Max 5x                       | $100/月。用量是 Pro 的 5 倍。                                                                                         |
| Max 20x                      | $200/月。用量是 Pro 的 20 倍。                                                                                        |
| 5x / 20x                     | 相对 Pro 的用量比例，不是独立单位。Pro 能发 100 条，Max 5x 能发 500 条，大概是这个意思，但 Anthropic 不公布具体数字。 |
| Session 用量                 | Claude 的用量按 session 计算，不是固定时间窗口，是模糊的会话边界。                                                    |
| Context window（上下文窗口） | 单次对话能处理的文本长度上限，比如 200K token ≈ 15 万字。和每天能发多少条消息是两个独立的天花板。                     |
| Claude Code                  | AI 编程 Agent。                                                                                                       |

### OpenAI 官方（ChatGPT）

| 术语            | 说明                                                                                                                                                               |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Free            | 免费版。                                                                                                                                                           |
| Go              | 介于 Free 和 Plus 之间的新档位，可以先忽略。                                                                                                                       |
| Plus            | $20/月。能用 GPT-5，有 Deep Research 和 Codex，但有量的上限。                                                                                                      |
| Pro $100（x5）  | 用量是 Plus 的 5 倍。中转站说的「Pro x5 号」一般来说就是这一档订阅的账号。                                                                                         |
| Pro $200（x20） | 用量是 Plus 的 20 倍。「Pro x20 号」同理。                                                                                                                         |
| 5 小时窗口      | Codex 专属的计量周期，不是整个订阅只能用 5 小时。Codex 按「每 5 小时内能运行多少次任务」计算，和普通聊天的消息限制独立。具体流转流程可以看国内的 GLM Coding Plan。 |
| Codex           | OpenAI 的 AI 编程 。                                                                                                                                               |

### 中转站

| 术语             | 说明                                                                                                                                                      |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 中转站           | 帮国内用户绕过支付和网络的中间商。                                                                                                                        |
| 官转             | 中转站持有真实 API Key，帮你转发请求。走的是真实 API，效果和官方一致。                                                                                    |
| 逆向渠道         | 破解网页版登录态，把 API 请求伪装成普通用户聊天发出去。没有 API Key。价格极低，随时可能被检测封号，违反服务条款。                                         |
| Token            | AI 计费的最小单位。英文约 1 词 = 1 token，中文约 1-2 字 = 1 token。输出比输入贵 3-5 倍。                                                                  |
| 倍率             | 中转站相对官方 API 价格的定价系数。倍率 1 = 同价，0.8 = 八折。不要贪便宜，但可以都试试。                                                                  |
| 美刀（虚拟额度） | 中转站内部记账单位，不是真实汇率兑换的美元。充 1 元人民币通常换 1 虚拟美元额度，各家不同。                                                                |
| 号池             | 中转站维护的一批真实订阅账号，排队分配给用户共享使用。「Pro x5 号」就是号池里放的 Pro $100 账号。账号随时可能被平台封禁，风险自担。一般来说都是这个意思。 |
| 满血             | 完整的官方模型，没有削减参数。                                                                                                                            |
| 阉割             | 用低级模型冒充高级模型，或限制输出长度、关闭部分功能。                                                                                                    |
| Base URL         | 使用中转站时，替换官方地址的那个中转服务器地址。                                                                                                          |
| OpenAI 兼容格式  | 事实行业标准。Claude、Gemini 的中转站也用 OpenAI 的接口格式，所以大部分客户端工具通用。                                                                   |
| 月抛站           | 运营周期极短的小型中转站，开几个月就跑路，充值有去无回。                                                                                                  |

## 使用前的检查清单

- 能否说明请求实际发送到哪里，是否保留日志或训练数据。
- 是否支持小额测试，避免一次性充值过多。
- 是否明确模型来源、倍率和失败退款规则。
- 是否要求提交账号 Cookie、登录态或其他高风险凭据。
- 是否准备了随时失效时的数据迁移和替代方案。

如果业务内容涉及隐私、客户数据或生产环境，应优先使用官方渠道并完成必要的安全评估。
