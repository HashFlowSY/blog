# Add more real project evidence

Status: ready-for-human

## Context

After fictional template cases are removed, the public portfolio contains one real Project Case: the personal blog itself. The old site audit correctly identified that one self-referential case is insufficient evidence for evaluating broader AI application, backend, or delivery experience.

## Required Input

Select two or more projects the author genuinely completed or participated in. For each, provide only facts safe for public disclosure:

- problem and context;
- personal role;
- duration;
- important constraints and decisions;
- implementation outline;
- outcome and available evidence;
- source or demo link when public;
- a real cover image safe to publish.

## Acceptance Criteria

- Every new public case describes real work.
- Claims distinguish personal contribution from team outcomes.
- Confidential details are removed or generalized without inventing results.
- Each case satisfies the strict Project Case contract.
